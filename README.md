# ForexJournal
📈 Forex Journal Mobile App


A high-performance, cross-platform mobile application built with React Native, specifically designed for active traders. This app was developed based on real-world trader requirements to facilitate disciplined trade logging and instant performance analytics.



🚀 Live DemoAndroid Build: [View/Download the Build on Expo](https://expo.dev/accounts/yatiraj_powar/projects/forexjournal/builds/3df6f240-462c-4765-8b2c-26151b6e1638)

✨FeaturesReal-Time Trade Journaling: Log entry/exit prices, stop-loss, and take-profit targets instantly.Performance Dashboard: View comprehensive monthly analytics including Win Rate, Total Trades, and Net P/L.Daily Audit Trail: A chronological history of all executed trades with detailed breakdown of pairs and outcomes.Psychological Tracking: Integrated "Notes" section for each trade to identify emotional patterns and market context (e.g., "NFP impact").Cross-Platform UI: Consistent and responsive design optimized for both Android and iOS ecosystems.




🛠️ Tech StackFramework: React Native (Expo)Language: TypeScript / JavaScriptState Management: Redux Toolkit (for complex state handling and persistence)Styling: Styled ComponentsLocal Database: AsyncStorage / SQLite
